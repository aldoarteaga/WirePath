# Fixtures

Small, deterministic captures used by the test suites. All but `sip-call.pcap` are generated by
`FixtureCatalog` (`Packages/WirePathCore/Sources/WirePathFixtures/FixtureCatalog.swift`):

```bash
cd Packages/WirePathCore && swift run wpsamplegen --fixtures ../../Fixtures
```

`FixtureTests.checkedInFixturesMatchTheCatalog` fails when a checked-in file no longer matches its generator.
Expected values in `FixtureTests` were cross-checked with tshark.

| File | Contents |
|---|---|
| `basic-ethernet.pcap` | ARP request/reply, ICMP echo, an 802.1Q-tagged UDP datagram, IPv6/UDP and a non-IP (LLDP) frame. |
| `ipv4-tcp.pcap` | One TCP connection: handshake, data, a segment missing from the capture, duplicate ACKs, a retransmission, an out-of-order segment and FIN teardown. |
| `udp.pcap` | DNS queries and answers, NTP, syslog, a plain UDP flow and an IPv4-fragmented datagram. |
| `application-protocols.pcap` | DHCP DORA (TFTP/SIP server options), DNS NAPTR/SRV, a TCP handshake with options, HTTP provisioning, TLS Client/Server Hello, STUN/ICE binding, TURN allocation (401 challenge, success, ChannelData), NTP, ICMP port unreachable, ICMPv6 neighbor discovery and a compound RTCP SR + SDES. |
| `sip-call.pcap` | One answered G.711 µ-law call through a proxy (simulator output, checked in; used by the UI tests). |
| `sip-problems.pcap` | SIP diagnostics: a REGISTER whose credentials are rejected, a REGISTER refused with 403, a 200 OK retransmitted without ACK, OPTIONS to a dead server (timeout), SUBSCRIBE 489 and MESSAGE 503 errors, a busy call, and an unanswered SIP-over-TCP SYN. |
| `rtcp-call.pcap` | One G.711 µ-law RTP stream (10 s, 5 packets lost) with Sender Reports, Receiver Reports acknowledging them (40 ms round trip), SDES CNAMEs and an RTCP XR VoIP-metrics block (MOS-LQ 3.4). |
| `webrtc-session.pcap` | Two ICE sessions seen from peer A behind a NAT. Session 1 (offer/answer over SIP with ICE candidates): a STUN server binding, a TURN Allocate challenged (401) then allocated, host→host checks that time out, a check relayed through a TURN channel, the host→srflx pair nominated, a DTLS 1.2 handshake, 3 s of Opus SRTP each way, a consent check and the relay released. Session 2: the STUN server never answers, TURN rejects the credentials and no pair answers, so ICE fails. Integrity values are placeholders. |
| `audio-codecs.pcap` | Five SIP calls for audio reconstruction: G.711 µ-law with three DTMF keys (RFC 4733), a 100 ms loss and a 1 s pause with comfort noise (RFC 3389); G.722 carrying a 200 Hz–3.1 kHz sweep and a 1 kHz tone; L16 at 16 kHz; G.729 (placeholder payloads: not decoded); and an SRTP call (RTP/SAVP with a placeholder SDES key). tshark decodes it without warnings and agrees on streams, loss and the RFC 4733 events. |
| `rtp-call.pcap` | One answered G.711 A-law call with a loss burst, jitter, reordering and duplicates on the caller's media. |
| `corrupted-capture.pcap` | A pcap whose only record claims more bytes than the file holds — rejected before any packet. |
| `damaged-capture.pcapng` | pcapng with capture metadata, two interfaces, sliced packets, truncated headers, a packet comment, interface drop statistics and a damaged final block — analyzable up to the damage. |

`webrtc-session.pcap` decodes cleanly in tshark: 45 STUN (16 TURN, including 2 ChannelData), 4 DTLS, 7 SIP/SDP and
300 RTP packets (`--enable-heuristic rtp_udp`), with no expert warnings.
